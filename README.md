# Laboration 2, DT209G - Introduktion till PHP
Detta är en laboration i _Webbutveckingsprogrammet_ på Mittuniveristetet.

## Länk till webbplats
[Min webbplats](https://studenter.miun.se/~hali2507/writeable/Laboration2/)

## Syfte
Syftet med laborationen är att få en introduktion till PHP med målet att skapa en enklare webbplats med HTML, CSS och objektorienterad PHP samt databasanslutning.
För denna laboration ska även AI-baserade verktyg provas.

## Uppgifter
Uppgiften består av flera delar som framgår i listan nedan:
 * skapa webbplats med 3 sidor (startsida, bucketlist och AI) med PHP,
 * koppling till SQL-databas med möjlighet att lägga till och ta bort via formulär,
 * använda objektorienterad PHP.
